# notes

过程记录。不放正式结论（结论进 `writeups/`），不放决定（决定进 `plan/07-decision-log.md`）。

| 子目录 | 内容 | 命名 |
|---|---|---|
| `reading/` | 阅读笔记。每篇 ★★★ 参考一页：它测了什么 regime、用了什么指标、没测什么、对本项目哪一章有用 | `YYYY-MM-DD-<slug>.md` |
| `discussions/` | 与人（或与 AI）讨论的整理稿；只留观点与分歧，不留原始对话 | `YYYY-MM-DD-<topic>.md` |
| `retro/` | 阶段复盘：计划 vs 实际、时间去哪了、下阶段调整 | `YYYY-MM-<phase>.md` |

## 阅读笔记模板

```markdown
# <标题>
来源：<链接或引用>  读于：YYYY-MM-DD  相关章节：ChN

## 他们测了什么
- 硬件 / 模型 / 负载 / 指标 / 对照

## 主要结论

## 他们没测什么（= 我们的补集）

## 可直接复用的东西
- 脚本 / 指标定义 / 数据集
```
