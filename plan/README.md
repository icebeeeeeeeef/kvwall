## 从哪里开始

先看 `09` 的最小前置与第一版项目，再按 `02` 的 Ch0/Ch1 搭小服务，参照 `03` 定义评测；`04` 只核验当前环境，`08` 只取当前问题。不要先把所有文档、模型和硬件都学完。

后续沿现象或明确适配需求补知识；准备面试时用 `05` 检查本人实际负责的代码与验证范围，而不是按技术名词打勾。

## 维护规则

方向性变更先写 `07`，相关文档同步更新；历史决定标注复审/废止，不让旧门槛继续生效。实验结果放 writeups/data，过程笔记放 notes；所有估算注明假设，实际数字附 run_id。单卡数据可以正式记录，但不能外推多卡或生产容量。
